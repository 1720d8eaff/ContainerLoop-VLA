# 真实机器人容器操作：公开展示子集

本目录是用户提供的 9 条原始真机采集记录中抽取的 3 条低分辨率展示样例，不是完整训练集，也不能据此推断成功率、300 条数据的质量或某算法性能。画面展示机器人双臂与容器操作；仅凭本子集不能确认具体控制策略、机器人型号及成功标签。

## 数据处理

- 原始图像元信息标注 30 FPS；每隔 6 帧抽取一帧并保留末帧，时间由帧号和标称帧率估算，并非已核验的真实时间戳。
- 只公开 color_3 视角，裁掉原图上方 96 像素后缩放，移除图像元数据；公开前仍应逐帧人工检查。
- 每个样例保留抽取帧对应的左右臂和夹爪状态、动作 qpos；单位、坐标系、动作语义及相机外参尚未核验。
- 该数据的 `depths` 为空，本展示子集不包含深度、音频、触觉或阶段标签。

详见各回合的 trajectory.json。仅作真实采集过程和数据结构展示。
