

## ContainerLoop-VLA

- 修复默认依赖：移除默认安装中的 GPU 模型栈与非法 Markdown 标记，保留原清单作为模型环境参考。
- 新增实际 MuJoCo 接触评测：重力、摩擦、圆柱接触代理、双指夹爪和位置伺服。48 个明确配置 × 5 组控制开关，共 240 次新实验，逐步 CSV、原始 JSONL。
- 新增官方 GR00T checkpoint 加载入口、RGB/状态/语言模态组装及物理动作验证。官方 `get_action` 已完成物理量还原；新增显式 7D codec 单独处理标准化的 xyz/旋转向量/夹爪输入，不对官方输出二次反归一化。
- 新增 RGB/深度文件读取、Brown-Conrady 相机模型反投影、仿射时钟修正与丢帧间隙报告。真实相机内参必须从设备/标定提供。
- 从现有硬件仓库提取并保存关节名、DDS 索引、URDF 哈希和限位、RH56H1 夹爪、D435I 来源以及 `CONTROL_DT=0.002` 的绑定索引。500 Hz 发布由同一项目的板端 DDS 后端（unitree-g1d-grasp）实现，本仓库的 `joint_pd` 提供对应周期的关节力矩计算，二者合起来构成规划到 500 Hz PD 执行的链路。
